## 🚀 快速安裝技能 / Quick Install

### 1. 安裝單一技能到 Antigravity / Install to Antigravity
```bash
# 例如安裝 faceless-explainer 到全域技能目錄 (~/.gemini/config/skills)
git clone https://github.com/clive520/agent-skills-hub.git /tmp/hub
cp -r /tmp/hub/skills/faceless-explainer ~/.gemini/config/skills/
rm -rf /tmp/hub
```

### 2. 安裝單一技能到 Claude Code / Install to Claude Code
```bash
# 例如安裝到 Claude Code 技能目錄 (~/.claude/skills)
git clone https://github.com/clive520/agent-skills-hub.git /tmp/hub
cp -r /tmp/hub/skills/faceless-explainer ~/.claude/skills/
rm -rf /tmp/hub
```

### 3. 一次複製所有技能 / Install All Skills
```bash
# Antigravity 全域技能
cp -r skills/* ~/.gemini/config/skills/

# Claude Code 技能
cp -r skills/* ~/.claude/skills/
```

## 🛠️ 如何新增或更新技能？（自動化中英編譯）
本資料庫已配置 GitHub Actions 自動化工作流程：
1. 在 `skills/<skill-name>/` 目錄下維護 `SKILL.md`（預設）、`SKILL_ZH.md`（繁中）與 `SKILL_EN.md`（英文）。
2. 推送至 GitHub：
   ```bash
   git add .
   git commit -m "feat: add or update skill"
   git push origin main
   ```
3. GitHub Actions 將自動讀取所有技能的雙語元數據、更新中英首頁索引、產出專屬文檔頁面，並在 1~2 分鐘內自動重新部署至 GitHub Pages！
